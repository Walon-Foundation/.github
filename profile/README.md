  ## What We Build

  | Domain | Project | Description |
  |--------|---------|-------------|
  | 💳 Fintech | [fundwave](https://github.com/Walon-Foundation/fundwave) | Crowdfunding platform with mobile money for Sierra Leoneans |
  | 🏥 Health | [tele-health](https://github.com/Walon-Foundation/tele-health) | Anonymous mental health counseling PWA |
  | 🏥 Health | [health-chatbot](https://github.com/Walon-Foundation/health-chatbot) | RAG-powered health assistant |
  | 🎓 Education | [edu-ai](https://github.com/Walon-Foundation/edu-ai) | AI-powered PDF learning and flashcard generator |
  | 🧭 Youth | [ikigai](https://github.com/Walon-Foundation/ikigai) | Mentorship and purpose platform for young Sierra Leoneans |
  | 💼 Business | [business-directory](https://github.com/Walon-Foundation/business-directory) | Real-time business verification directory for Sierra Leone |
  | 🤖 AI | [chatbotly](https://github.com/Walon-Foundation/chatbot-react) | Lightweight, customizable React chatbot component |
  | 🛠️ Dev Tools | [backend-starter-cli](https://github.com/Walon-Foundation/backend-starter-cli) | Scaffold production-ready backends in seconds |
  | 🦀 Dev Tools | [blast](https://github.com/Walon-Foundation/blast) | Fast, config-driven API load tester written in Rust |
  | 🌐 Language | [code-lang](https://github.com/Walon-Foundation/code-lang) | Interpreted programming language written in Go |

  ## Our Principles

  - **Offline-first** — built for 3G and low-bandwidth environments
  - **Mobile-money native** — integrates with the payment rails Sierra Leoneans actually use
  - **Open source** — all projects released under the MIT license
  - **Privacy-first** — no unnecessary data collection, ever
